HANOK INTERIOR / 유니티용 빈 한옥 실내

1. 설치
ZIP을 먼저 압축 해제합니다. Unity 프로젝트를 백업한 다음 HanokInterior.unitypackage를 더블 클릭하거나 Assets > Import Package > Custom Package에서 선택하고 Import합니다.
컴파일과 에셋 생성이 끝나면 Assets/HanokInterior/Generated 폴더가 생깁니다.
생성되지 않으면 Console의 빨간 오류를 확인하고 Tools > Hanok Interior > Create Missing Assets를 실행합니다.
Import 창이 비어 보이면 창을 닫고, ZIP 안의 Assets/HanokInterior 폴더 전체를 프로젝트 Assets 폴더에 복사하는 방식으로 설치할 수 있습니다. 두 방법 중 하나만 사용하세요.
Source 폴더의 .png.bytes는 의도한 형식입니다. 이름을 변경하지 마세요. 설치 스크립트가 직접 이미지 데이터를 읽어 Texture2D 에셋을 생성하므로 PNG 임포터 완료 시점에 의존하지 않습니다.

2. 화면에 넣기
먼저 Generated/HanokInterior_Preview.unity를 열면 카메라와 확인용 조명이 포함된 씬을 볼 수 있습니다. Play하면 고정 카메라 화면을 보여줍니다. 이동 조작 스크립트는 없습니다.
작업 중인 씬에는 Generated/HanokInterior.prefab을 Hierarchy로 끌어 놓으세요.
Transform Position=(0,0,0), Rotation=(0,0,0), Scale=(1,1,1)을 권장합니다.
Scene 뷰에서 선택 후 F로 전체를 찾으세요. Game 뷰는 자신의 카메라가 실내를 향해야 보입니다.
추천 카메라 위치=(3.4,1.8,-6.5), 바라볼 위치=(-0.8,2.65,5.5).
프리팹에는 조명과 카메라가 없습니다. 기존 게임의 조명을 사용하거나 확인용 씬의 Preview Lighting을 복사해 강도를 조절하세요.
흰 한지와 벽이 어두우면 재질보다 씬 조명부터 확인하세요. 표시된 PNG 미리보기는 실제 메시를 별도 렌더러로 그린 것이므로 Unity 조명 결과와 차이가 있습니다.

3. 규격과 구성
Unity 1 unit=1m 기준. 실내 바닥 가로 X=12m, 세로 Z=16m, 바닥 Y=0m, 벽 상부=3.5m, 용마루 최고=5.6m.
중앙 피벗은 바닥 중앙이며 RoomCenter 빈 오브젝트를 배치 기준으로 사용할 수 있습니다.
11개 메시, 8,680 삼각형. 4개 공유 재질. 텍스처: 나무 512, 마루 1024, 벽 256, 한지 256 픽셀 정사각형.
기둥, 대들보, 보 받침, 중도리, 서까래, 경사진 천장, 창살, 한지 면, 흰 벽, 목재 마루를 포함합니다.
가구, 장식품, 조명기구 모델, 외부 지붕, 마당은 없습니다.
창과 미닫이 형태의 한지 패널은 불투명하고 고정되어 있습니다. 문 열기나 외부 통로 기능은 없습니다.
외벽 뒷면을 감상하기 위한 모델이 아니며 벽/바닥/천장 일부는 안쪽만 보이는 면입니다.
바닥과 외곽 벽은 BoxCollider, 큰 목구조와 천장은 정적 MeshCollider입니다. Rigidbody를 붙이지 마세요. 이동 캐릭터는 별도 CharacterController 또는 3D 물리 구성이 필요합니다.
설치 후 기존 게임 스크립트와 자동 연동되지 않습니다. 런타임 전용 스크립트 없이 정적 환경으로 사용할 수 있습니다.

4. 렌더 파이프라인 및 최적화
Built-in Standard 또는 URP/Lit를 프로젝트에서 감지하여 재질을 생성합니다. Unity 2022.3 이상 및 Unity 6의 일반적인 API를 기준으로 작성했습니다.
HDRP 셰이더 선택 분기는 있으나 HDRP 조명/노출 설정은 별도로 필요하며 지원 검증 대상이 아닙니다.
설치 후 렌더 파이프라인을 바꾸면 기존 재질은 자동으로 덮어쓰지 않습니다. Unity 재질 변환 도구를 사용하거나 백업 후 Generated를 삭제하고 생성 메뉴를 다시 실행하세요.
메시에는 라이트맵용 보조 UV를 생성합니다. 베이크된 라이트맵은 포함하지 않습니다.
확인용 씬은 실시간 포인트 라이트 6개를 사용합니다. 모바일 등에서는 실제 게임에 맞게 베이크하거나 개수를 줄이세요. 폴리곤 수만으로 프레임 속도가 보장되지는 않습니다.
기존 Generated 에셋은 생성 메뉴로 덮어쓰지 않습니다. 새로 생성하려면 참조와 변경사항을 백업한 뒤 Generated 전체를 삭제하세요.

5. 원본과 검증 범위
Models/HanokInterior.obj와 .mtl, 4개의 PNG는 다른 3D 도구에서 편집할 수 있는 원본입니다. Unity 권장 설치는 unitypackage 또는 Assets 폴더 복사입니다.
Sources에는 메시/텍스처 제작 및 미리보기 Python 소스가 있습니다. 유니티 사용에는 Python이나 Blender 설치가 필요하지 않습니다.
메시 인덱스, 삼각형 면적, 텍스처 디코딩, 패키지와 ZIP 구조를 검사했습니다. 이 제작 환경에는 Unity Editor가 없어 실제 Unity 내 컴파일, 렌더링 및 플레이 검증은 수행하지 못했습니다.
